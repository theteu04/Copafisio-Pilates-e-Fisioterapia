# Copafisio Pilates & Fisioterapia

Site institucional responsivo de página única, criado com React, TypeScript e Vite.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm

## Instalação e execução

```bash
npm install
npm run dev
```

O Vite informa o endereço local no terminal.

## Build e pré-visualização

```bash
npm run build
npm run preview
```

O build de produção é gerado em `dist/`. Publique o conteúdo dessa pasta em um serviço de hospedagem estática compatível com Vite.

## Dados editáveis

Edite `src/clinic-config.ts` para atualizar telefone, WhatsApp, localização, horário, redes sociais, avaliações e perfil profissional. O número do WhatsApp deve conter apenas dígitos, com código do país e DDD.

A logo em `public/images/copafisio-logo.jpg` foi extraída do PDF original fornecido. As fotos do profissional e da clínica foram incluídas em `public/images/`.

Biografia do profissional permanece opcional. A clínica informou que não possui perfil próprio no Instagram. A nota, a quantidade de avaliações e os depoimentos exibidos foram fornecidos para publicação.
